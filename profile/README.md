# English

## About Geehy Semiconductor

Geehy Semiconductor is a fabless IC company specializing in industrial- and automotive-grade microcontrollers, mixed-signal analog ICs, and system-on-chip products. Backed by more than 20 years of IC design experience and embedded-system expertise, Geehy provides reliable products and solutions for accurate sensing, secure transmission, and real-time control across automotive, industrial, smart-energy, and consumer-electronics applications.

This GitHub organization hosts development resources, tools, reference projects, and application examples for APM32 microcontrollers.

Device compatibility, peripheral configuration, development environments, and setup steps vary by repository. Please read the README in the relevant project before use. To report a problem, open an Issue in the relevant repository and include the device model, development board, toolchain, reproduction steps, and key logs whenever possible.

# 中文

## 关于极海半导体

极海半导体是一家专注于工业级与车规级微控制器、混合信号模拟芯片及系统级芯片（SoC）的集成电路设计企业。依托二十余年的芯片设计经验与嵌入式系统能力，极海提供可靠的芯片产品和解决方案，助力汽车电子、工业控制、智慧能源及消费电子等领域实现精准感知、安全传输与实时控制。

本 GitHub 组织集中展示 APM32 微控制器相关的开发资源、工具、参考工程与应用示例。

## 使用与支持

每个仓库的适用芯片、外设配置、开发环境和使用步骤可能不同，请先阅读对应项目的 README。示例工程主要用于功能演示和开发参考；用于量产项目前，请结合目标芯片的数据手册、用户手册及实际硬件完成验证。

如需反馈问题，请在对应仓库提交 Issue，并尽量附上芯片型号、开发板、工具链、复现步骤和关键日志。
